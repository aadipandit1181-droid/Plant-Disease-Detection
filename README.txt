PlantVillage

Create one folder for each class, for example:

dataset/
  Apple___Apple_scab/
  Apple___Black_rot/
  Apple___healthy/
  Tomato___Early_blight/
  Tomato___Late_blight/
  Tomato___healthy/

Each class folder should contain leaf images (.jpg/.jpeg/.png).

Do not put all images directly inside dataset/.
